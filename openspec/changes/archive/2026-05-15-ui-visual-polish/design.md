## Context

Vanilla JS + Tailwind CDN SPA. 스토리보드 42슬라이드 와이어프레임을 직접 확인 후 현재 구현과 비교한 결과 레이아웃·색상·구조 차이를 식별했다. 기능 로직은 유지하고 UI 레이어만 수정한다.

## Goals / Non-Goals

**Goals:**
- 스토리보드 슬라이드와 1:1 시각 일치
- 각 화면의 레이아웃 구조 변경
- Tailwind 클래스로 색상/스타일 표현

**Non-Goals:**
- 기능 변경, API 변경
- 모바일 레이아웃 추가 변경 (이미 구현)

## Decisions

### 1. 로그인/회원가입 화면 분리
`LoginPage`에 `mode` 상태 추가 (`'login'` | `'signup'`). 모드별로 다른 HTML 렌더링. 전환은 하단 링크 클릭.
- 로그인 모드: "로그인" 버튼 + "계정이 없으신가요? **회원가입**" 링크
- 회원가입 모드: "가입하기" 버튼 + "이미 계정이 있으신가요? **로그인**" 링크

### 2. 칸반 컬럼 색상 (Tailwind)
| 컬럼 | 헤더 배경 | 컬럼 배경 |
|------|-----------|-----------|
| TODO | `bg-yellow-100 text-yellow-800` | `bg-yellow-50` |
| DOING | `bg-blue-100 text-blue-800` | `bg-blue-50` |
| DONE | `bg-green-100 text-green-800` | `bg-green-50` |

### 3. 카드 인라인 입력
`+` 클릭 시 `kb-inline-form` 모달 대신 `col-TODO` 컬럼 맨 위에 인라인 div 삽입. `Esc`로 제거.

### 4. 카드 상세 모달 2컬럼
```
┌──────────────────────────────┐
│ #110  JWT 미들웨어 구현    ✕ │
├───────────────┬──────────────┤
│ 상태  [TODO][DOING][DONE]    │
│               │   [저장]     │
│ 담당자 @me    │              │
│ 생성자 @leader│ [다른담당자] │
│ 생성시각      │   [🗑삭제]   │
└───────────────┴──────────────┘
```

### 5. 팀 멤버 사이드 패널
데스크탑(`>1024px / xl:`)에서 칸반 레이아웃 우측에 멤버 패널 고정 표시.
`members` 탭 클릭 시 패널 toggle. 모바일에서는 `#members` 페이지 유지.

### 6. 에러 박스 스타일
- 이메일 형식/중복 → `bg-red-50 border border-red-300 text-red-700` 박스
- 다른 팀 소속 → `bg-yellow-50 border border-yellow-300 text-yellow-700` 박스

### 7. 채팅 카운터 하단 바
1000자 이하: 숨김. 900자 이상: 우측 숫자 표시. 초과: 전체 바 `1,042 / 1,000  42자 초과  전송(불가)`.

## Risks / Trade-offs

- 인라인 입력 vs 모달: 인라인이 컬럼 레이아웃에 영향을 줄 수 있음 → 컬럼 상단에만 삽입하고 스크롤 처리
- 사이드 패널: 칸반 컬럼 너비가 줄어듦 → xl: breakpoint 이상에서만 표시
