## Why

스토리보드 와이어프레임의 시각적 레이아웃과 색상 디자인이 현재 구현에 반영되지 않았다. 기능은 동작하지만 스토리보드가 정의한 컬럼 색상 구분, 화면 구조(로그인 분리/팀선택 2컬럼/인라인 입력), 카드 모달 레이아웃, 사이드 패널 등이 모두 다른 상태다.

## What Changes

- **로그인/회원가입**: 별도 화면 전환 구조 — "가입하기" 버튼 + "이미 계정이 있으신가요? 로그인" 링크 / 반대도 동일
- **팀 선택**: 2컬럼 나란히 레이아웃 (새 팀 만들기 | 초대코드 합류)
- **칸반 컬럼 색상**: TODO=노란 배경, DOING=파란 배경, DONE=초록 배경 (헤더 포함)
- **카드 인라인 입력**: 모달 제거 → TODO 컬럼 내부 상단에 인라인 폼 등장
- **카드 상세 모달 레이아웃**: 2컬럼 — 왼쪽(#id/제목/상태/담당자/생성자/생성시각) + 오른쪽(저장/다른담당자지정/삭제 버튼)
- **팀 멤버**: `#members` 별도 페이지 → 칸반 우측 사이드 패널로 변경 (데스크탑 >1024px)
- **에러 박스**: 빨간/노란 배경 박스 스타일로 변경
- **채팅 1000자 카운터**: 입력란 우측 숫자 → 하단 전체 바 (`1,042 / 1,000  42자 초과  전송(불가)`)
- **헤더**: 좌측에 "TaskFlow" 로고 추가

## Capabilities

### Modified Capabilities
- `user-auth`: 로그인/회원가입 화면 분리 구조
- `team-management`: 팀 선택 2컬럼 레이아웃, 에러 박스 스타일
- `kanban-board`: 컬럼 색상, 인라인 입력, 카드 상세 모달 2컬럼, 사이드 패널
- `team-chat`: 1000자 카운터 하단 바

## Out of Scope

- 백엔드 API 변경 없음
- 기능 로직 변경 없음 — 순수 UI 레이아웃/스타일 변경
- `#members` 라우트는 유지 (모바일에서 사용)

## Impact

- **변경 파일**: `frontend/pages/login.js`, `frontend/pages/teams.js`, `frontend/pages/kanban.js`, `frontend/pages/chat.js`
- **API 변경 없음**
