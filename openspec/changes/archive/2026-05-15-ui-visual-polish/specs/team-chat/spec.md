## MODIFIED Requirements

### Requirement: 채팅 1000자 카운터 하단 바
1000자 초과 시 카운터가 입력창 내부 숫자 대신 하단 전체 바로 확장된다.

#### Scenario: 정상 입력 (900자 미만)
- **WHEN** 입력 중 900자 미만이면
- **THEN** 카운터가 표시되지 않는다

#### Scenario: 경고 구간 (900-1000자)
- **WHEN** 900자 이상 1000자 이하 입력 시
- **THEN** 우측에 `{n}/1,000` 카운터가 표시된다

#### Scenario: 초과 (1000자 이상)
- **WHEN** 1000자를 초과하면
- **THEN** 하단에 `{n} / 1,000  {n-1000}자 초과  전송(불가)` 바가 표시되고 전송 버튼이 비활성화된다
