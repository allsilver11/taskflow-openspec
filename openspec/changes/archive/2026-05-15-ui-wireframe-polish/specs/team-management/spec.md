## MODIFIED Requirements

### Requirement: 초대코드 크게 표시 + 복사
팀 생성 직후 초대코드를 큰 글자로 표시하고 클립보드 복사 버튼을 제공한다.

#### Scenario: 초대코드 발급 화면
- **WHEN** 팀 생성이 성공하면
- **THEN** "✓ 팀이 생성되었습니다!" 메시지와 함께 초대코드를 큰 글자로 표시
- **THEN** 📋 복사 버튼이 초대코드 옆에 표시된다

#### Scenario: 복사 버튼 클릭
- **WHEN** 📋 복사 버튼을 클릭하면
- **THEN** 초대코드가 클립보드에 복사되고 버튼이 "✓ 복사됨"으로 2초간 변경된다

#### Scenario: 칸반 시작하기 버튼
- **WHEN** 초대코드 화면에서 "칸반 시작하기 →" 버튼을 클릭하면
- **THEN** `#kanban` 화면으로 이동한다

### Requirement: 합류 후 팀 미리보기
초대코드로 합류 성공 시 팀 정보를 미리 보여준다.

#### Scenario: 합류 성공 미리보기
- **WHEN** 유효한 초대코드로 합류가 성공하면
- **THEN** "✓ {팀명} 팀이 확인되었습니다!" 메시지와 팀명, 멤버 수를 표시
- **THEN** "이 팀에 합류 →" 버튼 클릭 시 `#kanban`으로 이동
