## MODIFIED Requirements

### Requirement: 칸반 컬럼 색상 구분
각 컬럼은 고유한 배경색으로 시각적으로 구분된다.

#### Scenario: 컬럼 색상
- **WHEN** 칸반 보드가 렌더링되면
- **THEN** TODO 컬럼은 노란 배경, DOING은 파란 배경, DONE은 초록 배경으로 표시된다

### Requirement: 카드 인라인 입력 (컬럼 내부)
`+` 클릭 시 별도 모달이 아닌 TODO 컬럼 내부 상단에 인라인 입력 폼이 나타난다.

#### Scenario: 인라인 입력 등장
- **WHEN** TODO 컬럼의 `+` 버튼을 클릭하면
- **THEN** 컬럼 내부 상단에 제목 입력란과 담당자 드롭다운이 나타난다
- **THEN** `Enter` 저장, `Esc` 또는 취소 버튼으로 닫힌다

### Requirement: 카드 상세 모달 2컬럼 레이아웃
카드 상세/수정 모달이 좌측(정보)과 우측(버튼) 2컬럼으로 구성된다.

#### Scenario: 모달 레이아웃
- **WHEN** 카드를 클릭하여 상세 모달이 열리면
- **THEN** 좌측에 #id, 제목, 상태 버튼, 담당자, 생성자, 생성시각이 표시된다
- **THEN** 우측에 저장, 다른 담당자 지정, 삭제 버튼이 세로로 배열된다

### Requirement: 헤더 TaskFlow 로고
칸반 헤더 좌측에 "TaskFlow" 로고가 표시된다.

#### Scenario: 헤더 로고
- **WHEN** 칸반/채팅/멤버 화면의 헤더를 보면
- **THEN** 좌측에 "TaskFlow" 텍스트 로고가 표시된다

### Requirement: 팀 멤버 사이드 패널 (데스크탑)
데스크탑(>1024px)에서 멤버 탭 클릭 시 칸반 우측에 멤버 패널이 슬라이드인된다.

#### Scenario: 멤버 패널 표시
- **WHEN** 데스크탑에서 "멤버" 탭을 클릭하면
- **THEN** 칸반 우측에 팀 멤버 목록 패널이 나타나고 칸반 컬럼이 좁아진다
