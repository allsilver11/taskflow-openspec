## MODIFIED Requirements

### Requirement: 팀 선택 2컬럼 레이아웃
팀 미가입 상태에서 "새 팀 만들기"와 "초대코드로 합류"가 나란히 2컬럼으로 표시된다.

#### Scenario: 팀 미가입 화면 레이아웃
- **WHEN** team_id=NULL인 사용자가 팀 선택 화면에 진입하면
- **THEN** "새 팀 만들기" | "초대코드로 합류" 2컬럼이 나란히 표시된다

### Requirement: 초대코드 에러 박스 색상 구분
에러 종류에 따라 박스 색상이 다르다.

#### Scenario: 형식/미존재 에러
- **WHEN** 형식 오류(400) 또는 미존재(404) 에러 발생 시
- **THEN** 빨간 배경 박스로 에러 표시

#### Scenario: 다른 팀 소속 에러
- **WHEN** 이미 다른 팀 소속(409) 에러 발생 시
- **THEN** 노란 배경 박스로 에러 표시
