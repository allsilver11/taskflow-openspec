## MODIFIED Requirements

### Requirement: 로그인/회원가입 화면 분리
로그인과 회원가입은 별도 모드로 전환된다. 기본은 로그인 모드.

#### Scenario: 로그인 모드 기본 화면
- **WHEN** 로그인 화면 진입 시
- **THEN** "로그인" 제목 + "로그인" 버튼 1개 + "계정이 없으신가요? **회원가입**" 링크가 표시된다

#### Scenario: 회원가입 모드 전환
- **WHEN** "회원가입" 링크를 클릭하면
- **THEN** "회원가입" 제목 + "가입하기" 버튼 1개 + "이미 계정이 있으신가요? **로그인**" 링크로 전환된다

#### Scenario: 에러 박스 스타일
- **WHEN** 이메일 중복(409) 에러가 발생하면
- **THEN** 빨간 배경 박스(`bg-red-50 border-red-300`) 형태로 에러 메시지가 표시된다
