## MODIFIED Requirements

### Requirement: 회원가입/로그인 로딩 상태
API 호출 중 버튼이 로딩 상태로 변경되어 중복 클릭을 방지한다.

#### Scenario: 처리 중 버튼 상태
- **WHEN** 가입하기/로그인 버튼을 클릭하면
- **THEN** 버튼 텍스트가 "처리중…"으로 변경되고 disabled 상태가 된다
- **THEN** API 응답 후 버튼이 원래 상태로 복구된다

### Requirement: 인라인 필드 에러
에러 메시지가 각 입력 필드 바로 아래에 인라인으로 표시된다.

#### Scenario: 이메일 형식 오류
- **WHEN** 올바르지 않은 이메일 형식으로 가입 시도하면
- **THEN** 이메일 필드 아래에 "⚠ 올바른 이메일 형식이 아닙니다" 표시

#### Scenario: 이메일 중복
- **WHEN** 이미 가입된 이메일로 가입 시도하면
- **THEN** 이메일 필드 아래에 "✕ 이미 가입된 이메일입니다" 표시 (409)

#### Scenario: 비밀번호 미달
- **WHEN** 8자 미만 비밀번호로 가입 시도하면
- **THEN** 비밀번호 필드 아래에 "⚠ 8자 이상 입력해주세요" 표시
